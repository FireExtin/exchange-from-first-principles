# 08 Margin Model

[English](#english) · [中文](#中文)

## English

Purpose: turn positions, marks, and account equity into margin checks.

## Status

Status: design scaffold. No runnable implementation exists here yet.

First implementation should cover:

- spot available balance;
- frozen balance;
- linear contract notional;
- initial margin;
- maintenance margin;
- liquidation threshold placeholder.

Use scaled integers. Detailed formulas should be backed by tests.

## 状态
